About

RAD syllabus ballet classes from Pre-School through Grade 8/Vocational, across multiple Malahide venues (Tennis Club, parish halls, local schools).

30-min class €95 · 45-min class €115 · 60-min class €125 · 75-min class €140. Trial classes can be booked any time of year.

Where

Malahide, Dublin. Classes run at St. Nicholas Hall, Malahide Parish Centre, St. Andrew's School & Parish Centre, St. Oliver Plunkett N.S., St. Andrew's Parish Centre, St. Sylvester's Infant School, St. Andrew's School.
